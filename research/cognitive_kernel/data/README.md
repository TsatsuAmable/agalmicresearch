# Cognitive Kernel consequence data

This directory is intentionally empty of outcome records at protocol freeze.

Use `npm run record:kernel-consequence -- ...` to append a complete record only after a task condition is finished and verified.

Historical Agalmic work is **not** backfilled as a clean control. The pilot is prospective because condition assignment, verification, and attention measurement were not fixed in advance for prior work.

The study manifest is frozen in `../CONSEQUENCE_PILOT_MANIFEST.json`. Any amendment after outcome inspection must be versioned and labelled exploratory.
